# Saved run configurations

Snapshots from `experiments/`, `experiments_debug/`, and
`DSBM_N_BRIDGES_KTH_v2/`, preserving the original relative paths and file contents.

Each run includes its saved Python configuration and parameter summary.
Checkpoint metadata is included where available. Summaries record runtime
parameters, including seeds and command-line overrides.

The source experiment directories remain in place. Checkpoints, trajectories,
videos, and logs are stored in those directories.
